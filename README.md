# ShoppyGlobe – React E-Commerce Project

This is a simple e-commerce application built using **React + Vite**, created as per the assignment instructions.

The project includes:
- Product listing  
- Product detail page  
- Add to cart  
- Remove from cart  
- Quantity increase/decrease (not below 1)  
- Search filter using Redux  
- Checkout page with dummy form  
- Order placed + Cart cleared  
- Routing with dynamic product detail  
- Lazy loading all components  
- Responsive UI  

---

## 🔧 Tech Stack

- React (Vite)
- React Router DOM
- Redux Toolkit
- JavaScript (ES6)
- CSS (Responsive)
